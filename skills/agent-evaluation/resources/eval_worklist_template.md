# Agent 评测体系全流程落地工作单（Project Eval Worklist）

> **使用说明**：将本清单复制到项目的 `docs/` 目录下，在推进评测基建或发版前逐项打勾核对。

---

## 阶段一：划清边界与确定性单测（不调大模型，0 成本秒跑）
- [ ] **剥离纯函数**：已将算分加权、等级映射、数值容差比对、复习排期、前置护栏正则剥离至 `domain/` 纯函数，**代码直接忽略大模型自报的分数/结论**
- [ ] **脱机单测门禁**：配置 `make verify`（`pytest` / `vitest`）默认阻断外网调用，全量运行耗时 $< 15$ 秒
- [ ] **HTTP 请求体逐字节快照（Request Snapshot）**：已在传输层拦截发往大模型的完整 JSON Payload，为核心场景建立逐字节快照基线（重构或升 SDK 时必须全绿）
- [ ] **零调用反向断言**：所有前置护栏拦截、额度超限、权限拒绝的单测，均已断言 `llm_call_count == 0` 且未写库、未扣费
- [ ] **评测漂移守卫（Drift Guards）**：已有单测强制断言“离线评测 Task 传给 Agent 的参数结构”与“线上 API 端点传给 Agent 的参数结构”完全一致

---

## 阶段二：构建高区分度金标数据集（Golden Datasets）
- [ ] **按职责拆分套件**：已按模块拆分为独立套件（如 `retrieval`、`grading`、`tutor`、`variants`、`summary`、`memory`）
- [ ] **检索金标与跑题负例**：已复用业务现有映射构建检索金标，同时报告**精确口径**与**父子小节宽松口径**；已配齐 20+ 条跑题负例标定 Rerank 分数下限
- [ ] **判分受控扰动矩阵**：每道核心主观题已按“全对（换解法）、部分对（单步错+错误传导）、全错（仅结论无过程）”构造扰动样本，并核实全部计算数字
- [ ] **反向红线用例（Reverse Cases）**：已为记忆写入、工具触发配齐 10+ 条“绝不该记/绝不该调”的反向用例（含 Prompt 注入、PII 隐私、临时草稿），门禁要求 `100%` 通过
- [ ] **数据集 SHA256 指纹**：已接入 `dataset_fingerprint.py`，严格遵守**“先改考卷建基线（Commit 1）、再改答题比高低（Commit 2）”**

---

## 阶段三：确定性评估器与模型评委校准（LLM-as-a-Judge）
- [ ] **确定性评估先行**：已实现草稿话泄漏检测（`draft_leak`）、基于 Trace 已见材料白名单的虚构引用核对（`fabricated_citations`）、以及可读性分块检查
- [ ] **跨家族异构与全盲化**：评委模型与被测业务模型分属不同厂商家族；导出待评任务采用盲号（Blind ID），并物理隔离映射表与答案目录
- [ ] **Pairwise 哈希翻转与工具材料补齐**：A/B 对比已按哈希翻转先后顺序；多轮对话中 Agent 动态调工具查出的内容已完整补入评委参考材料
- [ ] **严重度强绑定（治老好人偏见）**：评委 Rubric 强制标注 `severity: "error" | "minor"`，且通过 `check_verdicts.py` 强制执行“有 `error` 则对应维度得分必须 $\le 3$ 分”
- [ ] **盲种子防作弊与校准**：每次全量评测混入 3 条已知缺陷盲种子（检出率 $<80\%$ 告警）；已完成与人类专家/参照集的首次校准（一致率 $\ge 80\%$，记录 TPR / TNR）

---

## 阶段四：日常运行纪律与线上质量飞轮
- [ ] **快慢分层运行**：日常调参用 `QUICK=1` 快速档（禁止晋升）；正式提交前必跑全量档（显式设置 `timeout=900, retries=0` 防止超时静默重跑烧钱）
- [ ] **手动晋升基线（Manual Promote）**：基线仅允许通过 `make eval-promote` 手动更新，且 `thresholds.toml`、`baselines/`、`reports/` 必须与代码改动在同一个 Commit 提交
- [ ] **配置显式打印与 $2\sigma$ 容差**：评测报告首行显式打印生效的模型与 Thinking 模式（偏离生产缺省立即告警）；核心指标容差已按同配置连跑 3 次的 $\max(2\sigma, 1/N)$ 标定
- [ ] **三层可观测防泄漏隔离**：本机 Phoenix 存完整正文（配三道防线严禁推上云端）；云端 APM 执行 15 字段白名单脱敏 + 尾部采样（错误/慢请求/点踩 100% 保留）；自有库 `usage_ledger` 记全量账单（成功/失败/中断均记账）
- [ ] **每周 30 分钟线上分诊飞轮**：每周定期拉取线上点 👎 回复与用户人工改判（`self_grade <> auto_grade`），复现后沉淀为新金标用例
